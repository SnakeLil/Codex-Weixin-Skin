## Codex WeChat Skin v1.1.0

This is the first release with the native one-click macOS installer and the
project's complete compatibility and safety toolchain.

### Highlights

- **One-click DMG:** includes a universal Apple Silicon + Intel installer app.
- **Current compatibility:** validated with ChatGPT/Codex `26.820.60940`
  (build `7119`) on Apple Silicon and macOS 15.5.
- **Full UI coverage:** chat, search, settings, Sites, Scheduled Tasks, Plugins,
  and pinned summary layouts are covered by isolated regression tests.
- **Privacy-safe diagnostics:** exports only allowlisted environment, payload,
  and compatibility facts.
- **Full + Lite consistency:** both editions consume the same canonical WeChat
  design tokens.

### Install

Download `Codex-Weixin-Skin-v1.1.0.dmg`, open it, and double-click
**Install Codex WeChat Skin.app**. The community build is ad-hoc signed but is
not Apple-notarized, so the first launch may require right-clicking the app and
choosing **Open**, or using **System Settings → Privacy & Security → Open
Anyway**.

The installer will not force-quit Codex. Save your work and quit Codex yourself
before installing or re-applying the Full theme.

### Assets

- `Codex-Weixin-Skin-v1.1.0.dmg` — recommended graphical installer
- `Codex-Weixin-Skin-v1.1.0.zip` — legacy command-based package
